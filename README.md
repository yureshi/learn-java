# ☕ Java Fundamentals for QA Engineers

A structured learning journey through **Java fundamentals**, created with a focus on building programming knowledge that can be applied to **software testing and test automation**.

This repository contains learning notes, code examples, exercises, and practical activities designed to gradually build Java knowledge from beginner level to a complete working application.

## 🎯 Goal

The goal of this repository is to build a strong foundation in Java by learning concepts through **practical examples and a real project**, rather than studying concepts in isolation.

The main project used throughout the learning path is a:

> **Console-based Library Management System**

The project evolves as new Java concepts are introduced.

## 📖 Learning Approach

The recommended approach is:

1. Read the concept.
2. Understand why it exists.
3. Type the example yourself.
4. Experiment with the code.
5. Complete the activity.
6. Move to the next topic only after understanding the previous one.

The focus is on **learning by doing**.

## 🚀 Why Java for QA?

Java is widely used in automation and software engineering. Building a solid Java foundation can help QA Engineers understand and work with areas such as:

* UI test automation
* API automation
* Test frameworks
* Automation frameworks
* Object-oriented test design
* Data handling
* Test utilities
* CI/CD automation

This repository focuses on the **Java foundation** needed before moving into more advanced automation topics.
